## Retouches images (rappel)
1. Unifier l'accent couleur (cobalt + ambre) sur les 6.
2. Poser le **logo** sur chaque visuel.
3. Retirer l'étoile ✦ (filigrane Gemini).
4. Refaire `bugs-resolve` (style « logos propres » comme `dev-web`).
5. Générer les illustrations **sans texte**, ajouter titre + logo dans Canva.

## Règles ComeUp à respecter
- Aucune coordonnée ni lien externe avant commande (email, tel, URL, réseaux).
- Titre = prestation de **base** (sans option) — pas trompeur.
- Paliers **chiffrés** (jamais « simple/intermédiaire/complexe » seuls).
