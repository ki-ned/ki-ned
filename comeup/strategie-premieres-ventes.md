# Stratégie — décrocher les premières ventes

Le seul vrai blocage à 0 avis, c'est la **confiance**. Objectif : **3-5 avis** le plus vite possible, puis remonter les prix.

## 1. Offre d'appel (casser le mur du 0 avis)
- Bug-fix **Basic à 20 € / 24 h** = achat à faible risque → ton 1er contrat. **Sur-livre** (corrige + explique la cause + un petit bonus).
- Optionnel : un gig « **audit** » ultra-cheap (10 €) : « J'audite votre projet React et vous liste quoi corriger ». Zéro risque, débouche sur du dev.

## 2. Réactivité = classement
- Réponds en **minutes**, pas en heures. ComeUp affiche et favorise les vendeurs actifs/rapides.
- Active les notifications ComeUp sur ton téléphone.

## 3. Preuve réelle > visuels stylés
- Ajoute des **captures de ton vrai travail** en 2ᵉ/3ᵉ image de chaque service (voir [README](README.md)).
- Une courte **vidéo de présentation** (30-60 s) booste énormément la conversion à 0 avis.

## 4. Amène ton propre trafic
- Partage tes services ComeUp sur **LinkedIn / tes réseaux** → des acheteurs qui te connaissent déjà = 1res ventes faciles.
- Ton réseau qui a un **vrai** petit besoin : commande via ComeUp, tu livres, avis **honnête**. ⚠️ Jamais de faux avis (bannissement).

## 5. Soigne chaque première commande
- Livrable propre + message de remerciement + **demande polie d'un avis**.
- Un client satisfait → propose-lui un palier supérieur ou un autre service (upsell).

## 6. Itère
- Après 3-5 avis : **augmente les prix** partout, retire l'offre d'appel à 20 € (ou monte-la à 30-35 €).
- Regarde quels services se vendent → double sur ceux-là, ajuste les autres.
